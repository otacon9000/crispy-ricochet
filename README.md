# crispy-ricochet

Top-down arcade shooter built in Unity 6. You fire projectiles that bounce off walls — every shot you fire can come back to kill you.

Built as a portfolio project targeting WebGL (playable in browser, no download required).

## Gameplay
- Move with WASD / left stick
- Aim and shoot with mouse / right stick
- Projectiles bounce off walls and persist for a limited number of hits
- Destroy wall blocks to open new space
- Your own projectiles damage you — manage the chaos you create

## Tech Stack
- **Engine:** Unity 6 (6000.x.x)
- **Render Pipeline:** Built-in 3D Core
- **Input:** Unity Input System (New)
- **Target Platform:** WebGL

## Getting Started
1. Clone the repository
2. Open with Unity Hub — use Unity version `6000.4.x`
3. Open scene: `Assets/Scenes/Main.unity`
4. Press Play
